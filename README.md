# U&I Express Website — gói bàn giao

- `index.html`: prototype tự chạy trong một file, mở trực tiếp bằng trình duyệt. Cần internet để tải font và dữ liệu bản đồ.
- `assets/img/brand/`: logo U&I Express, gồm bản nền sáng và bản chữ trắng cho nền tối.
- `assets/img/logos/`: logo đối tác và khách hàng, giữ nguyên màu gốc.
- `prompts/`: prompt Claude Code, gồm bản web tĩnh (HTML/CSS/JS) và bản Next.js.
- `source/`: file nguồn thiết kế (chỉ để tham khảo).
